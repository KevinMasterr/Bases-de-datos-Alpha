## Estructura del Repositorio

- `frontend/`: Código fuente de la interfaz de usuario y vistas de la aplicación.

- `postgresql/`: Scripts y configuraciones para la versión compatible con PostgreSQL.
- `docs/`: Documentación del proyecto (diagramas, manuales, etc.).
